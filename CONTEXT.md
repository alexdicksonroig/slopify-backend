# Slopify

The commerce domain for managing and presenting products offered through Slopify.

## Language

**Product Thumbnail**:
The optional image that visually represents a Product in compact views such as catalog lists, carts, and summaries.
_Avoid_: Primary image, product image

**Variant**:
A configurable Product dimension with a fixed set of possible options and an untranslated English label that the frontend translates. For example, a Color Variant can offer Red and Blue.
_Avoid_: SKU, purchasable variant
